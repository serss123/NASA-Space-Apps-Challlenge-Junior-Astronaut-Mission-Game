SOL A SOL · VERSIÓN 2 EN PROGRESO (copia del 15 de noviembre de 2026)
======================================================================

Esta es una copia de trabajo a mitad del rediseño. Ya incluye:
- La nueva base visual: colores, iconos propios, cielo animado, el Sol con
  caras según la tormenta, la Tierra como Control de Misión y ventanas que
  no se desplazan.
- La marca «Hecho con IA» en pantalla.
- Ya no está la «misión de clase» (código de partida y misión del día).
- Los textos reescritos para niños de 7 a 12 años (glosario, diario de
  descubrimientos, misiones, datos curiosos y noticias del Sol).

Todavía falta rediseñar cada pantalla (menú, partida, paneles, informes,
diario...), así que algunas pueden verse a medio hacer o mezclar el estilo
viejo con el nuevo. La versión anterior completa está en Sol-a-Sol.zip.

Tests de esta copia: todos pasan (tests 238 · pass 238 · fail 0).


PARA JUGAR (no hay que instalar nada)
-------------------------------------
1. Descomprime el zip.
2. Haz doble clic en «JUGAR - Sol a Sol.html».
3. Se abre en tu navegador (Chrome, Edge o Firefox).


CÓDIGO FUENTE
-------------
La carpeta «codigo-fuente» tiene el proyecto tal como está ahora.
Necesitas Node.js 20.19 o más nuevo (https://nodejs.org):

    cd codigo-fuente
    npm run setup
    npm run dev          (abre http://localhost:5173)

La guía del rediseño (en inglés) está en codigo-fuente/docs/DESIGN.md.
